# PPB_Emulator

Исторический UDP-имитатор ППБ/датчика для проверки обмена. По текущему назначению владельца развитие утилиты не планируется.

- `main.cpp` — точка входа.
- `udpserver.*` — обмен.
- `ppbemulator.*` — состояние и моделируемые ответы.

## Ограничение сборки

CMake задаёт C++17 и Qt5/Qt6 Widgets/Network, но ссылается на исходники `../PPB_Tester_Software/core/communication/`. Самостоятельный checkout не содержит эту зависимость; автономная сборка не гарантирована.

Действующая линия тестера: [PPB_Project](https://github.com/Anatolichka2202/PPB_Project). Эмулятор не является его автоматически подключаемым модулем.
